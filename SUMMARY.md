# Итоговая сводка: Внешний GigaChat API vs Локальная модель

## Ответ на вопрос

**Вопрос:** "Имеет ли тут смысл внешний GigaChat? Или стоит попробовать свою локальную модель использовать?"

**Короткий ответ:** Для развертывания на VM с Debian 12 **локальная модель через Ollama** является оптимальным выбором.

---

## Что было реализовано

### ✅ Гибкая система выбора модели

Проект теперь поддерживает **три варианта провайдеров моделей**:

1. **GigaChat API** (внешний, по умолчанию)
   - Для быстрого старта
   - Требует только API ключ
   - Сохранена полная обратная совместимость

2. **Ollama** (локальная модель, **рекомендуется для Debian 12**)
   - Простая установка через автоматизированный скрипт
   - Полная конфиденциальность данных
   - Экономия на API (~40,000₽/месяц для типичного использования)

3. **HuggingFace Transformers** (локальная модель, для продвинутых)
   - Максимальная гибкость и контроль
   - Большой выбор моделей
   - Возможность файн-тюнинга

### ✅ Простое переключение через конфигурацию

Переключение между провайдерами — одна строка в `.env`:

```env
# Для GigaChat API
MODEL_PROVIDER=gigachat

# Для локальной Ollama
MODEL_PROVIDER=ollama
```

---

## Почему локальная модель на Debian 12 — лучший выбор

### 1. 💰 Экономическая эффективность

**Типичная нагрузка (100 пользователей, 10 сообщений/день):**

- **GigaChat API:** ~45,000₽/месяц
- **Ollama на VPS:** ~5,000₽/месяц
- **Экономия:** 480,000₽/год

Окупается за 3-4 месяца.

### 2. 🔒 Конфиденциальность

- Все данные остаются на вашем сервере
- Нет передачи данных третьим лицам
- Соответствие требованиям NDA и ФЗ-152
- Идеально для корпоративного использования

### 3. 🎯 Независимость

- Нет зависимости от внешних API
- Нет rate limits
- Работает без интернета (после установки)
- Полный контроль над поведением модели

### 4. 🚀 Простота развертывания

Автоматизированный скрипт делает установку тривиальной:

```bash
bash setup_debian12.sh
```

30 минут — и у вас работающая система.

## Быстрый старт на Debian 12

### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/Sin7009/AI-Cortex.git
cd AI-Cortex
```

### Шаг 2: Запуск автоматической установки

```bash
bash setup_debian12.sh
```

Скрипт автоматически:
- Установит Ollama
- Загрузит выбранную модель (рекомендуется llama3.2)
- Настроит системный сервис
- Создаст виртуальное окружение Python
- Установит все зависимости
- Создаст файл .env

### Шаг 3: Запуск бота

```bash
source venv/bin/activate
python main.py
```

Или через systemd (если выбрали при установке):
```bash
sudo systemctl start ai-cortex.service
```

**Готово!** Бот работает с локальной моделью.

- **CPU:** 4 ядра

- **Disk:** 20 GB свободного места
- **Network:** Стабильное подключение (только для установки)

### Рекомендуемые характеристики

- **CPU:** 8+ ядер
- **RAM:** 16 GB
- **Disk:** 50 GB SSD
- **GPU:** NVIDIA с 8+ GB VRAM (опционально, ускоряет в 3-5 раз)

### Производительность

**Без GPU (CPU только):**
- Время ответа: 5-15 секунд
- Одновременные запросы: 1-2

**С GPU:**
- Время ответа: 1-3 секунды
- Одновременные запросы: 3-5

Для телеграм-бота с типичной нагрузкой CPU достаточно.

2. Оцените реальную нагрузку и требования

1. Разверните **Ollama на Debian 12** для основной работы

3. Настройте мониторинг (htop, journalctl)

```env

OLLAMA_MODEL=llama3.2

# Резервный вариант (если локальная модель недоступна)
GIGACHAT_API_KEY=your_key
```
