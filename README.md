# Cortex: AI-Assistant for Executive Communication

**Кортекс** — это интеллектуальная система премодерации и улучшения контента перед отправкой руководству. Бот выполняет функцию "цифровой префронтальной коры": он фильтрует информационный шум, структурирует данные и адаптирует стиль коммуникации под корпоративные стандарты.

Система работает в двух режимах: **глубокий анализ отчетов** (с использованием RAG) и **стилистическая коррекция сообщений** (Style Transfer).

-----

## Ключевые возможности

### 1\. Валидация отчетов (RAG Pipeline)

  * **Сравнение с эталоном:** Загруженные файлы (.pdf, .docx) автоматически векторизуются и сравниваются с базой "золотых стандартов" (Best Practices) с помощью **ChromaDB**.
  * **Структурный анализ:** LLM проверяет наличие обязательных разделов (Введение, Методология, Инсайты, Выводы).
  * **Executive Summary:** Автоматическая генерация "One-Pager" — выжимки на один экран с выделением 3 главных рисков и возможностей. Используется параллельная обработка через `asyncio.gather` для скорости.
  * **Smart Chunking:** Большие документы (до 100+ страниц) разбиваются на смысловые фрагменты (чанки) с перекрытием, что позволяет анализировать контекст без потери смысла.

### 2\. Рерайтинг сообщений (Style Transfer)

  * **Умная критика:** Бот анализирует входящий текст, выявляет "воду", панибратство и нечеткие формулировки.
  * **Два режима генерации:**
      * *Строго-официальный:* Для протокольной переписки.
      * *Лаконично-деловой:* Для оперативного решения вопросов.
  * **Интерактивный выбор:** Пользователь выбирает лучший вариант через Inline-клавиатуру, что создает петлю обратной связи (RLHF).

## Технологический стек

  * **Language:** Python 3.11+
  * **Framework:** `aiogram 3.x` (полностью асинхронная архитектура).
  * **LLM & Embeddings:** GigaChat Pro (SberDevices) + LangChain Integration.
  * **Vector Store:** ChromaDB (локальное персистентное хранилище).
  * **NLP & Parsing:** `langchain`, `pypdf`, `python-docx`, `Regular Expressions`.
  * **Security:** Поддержка работы в корпоративном контуре (`verify_ssl_certs=False`).

## Установка и запуск

### Предварительные требования

  * Python 3.10 или выше.
  * Доступ к API GigaChat.
  * Telegram Bot Token.

### 1\. Клонирование репозитория

```bash
git clone https://github.com/your-username/ai-cortex.git
cd ai-cortex
```

### 2\. Создание виртуального окружения

```bash
python -m venv venv
source venv/bin/activate  # Для macOS/Linux
venv\Scripts\activate     # Для Windows
```

### 3\. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4\. Настройка окружения

Создайте файл `.env` в корне проекта и добавьте свои ключи:

```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
GIGACHAT_API_KEY=your_gigachat_auth_key
```

### 5\. Запуск

```bash
python main.py
```

*При первом запуске система автоматически инициализирует ChromaDB и наполнит её синтетическими данными из `mock_data.py`.*

## Структура проекта

  * `main.py` — Точка входа. Инициализация бота, диспетчера и сервисов.
  * `handlers.py` — Слой обработки событий Telegram (роутинг сообщений и файлов, клавиатуры).
  * `services.py` — Ядро бизнес-логики:
      * `VectorDBManager`: Управление ChromaDB и эмбеддингами.
      * `ReportValidator`: Логика RAG, валидация и суммаризация.
      * `MessageRewriter`: Промпт-инжиниринг и парсинг ответов LLM.
  * `mock_data.py` — Набор синтетических "идеальных" примеров для холодного старта системы.

## Инсайты реализации

### Научный подход (Neuroscience perspective)

Работа бота основана на принципе минимизации **семантической энтропии**. Преобразуя хаотичный входной сигнал (черновик отчета) в структурированный вывод, мы снижаем когнитивную нагрузку на рабочую память руководителя (Working Memory Capacity). Генерация саммари позволяет обойти ограничение "7±2 объекта", предоставляя информацию в сжатом, готовом к инференсу виде.

### Бизнес-ценность (ROI)

Внедрение «Кортекса» решает проблему **асимметрии контекста**. Исполнитель всегда знает детали, CEO нужно только решение. Бот выступает в роли "информационного автоклава", стерилизуя данные от эмоций и лишних подробностей. Это напрямую увеличивает **Decision Velocity** (скорость принятия управленческих решений) в команде.
